# La Boîte à Parfums — maquette de démonstration

Maquette de démonstration **non officielle** du site de l'institut de beauté La Boîte à Parfums (Oraison), réalisée par Vocaliz à titre de proposition.

- Site : https://justinbbz.github.io/boite-a-parfums/
- Les créneaux affichés sont des exemples, les tarifs sont indicatifs, aucun paiement n'est effectué et aucun rendez-vous n'est enregistré.
- Page non indexée par les moteurs de recherche.
- Photos : page Facebook de l'institut. Film d'accueil : Mixkit (licence libre).

Le site (HTML, CSS, JavaScript, images) est publié à partir des deux archives `site-part1.zip` et `site-part2.zip`, décompressées par `.github/workflows/pages.yml` à chaque envoi sur la branche `main`.
